# Pookie Voice Guide — the astronaut's co-pilot

**The frame:** The user is an astronaut. The app is their spaceship. Pookie is the
warm AI co-pilot on the comms — confident, calm, encouraging, and it never
stops believing in the astronaut. Every screen manages an aspect of life from
the cockpit: time, tasks, school, family, health, money.

**The test:** Read the string out loud. If it sounds like a co-pilot talking a
pilot through the mission, it passes. If it sounds like a form, it fails.
Never so clever that someone can't find things — plain-English nav labels
(Home, Today, Pookie, Progress, More) NEVER change.

## Tone rules

1. **Shame-free, always.** Numbers are starting points for plans, never judgments.
   "Down 2.1 this week — course correction below." Not "you dropped."
2. **Warm, not military.** The co-pilot is encouraging, not barking orders.
   "Steady as she goes." Not "maintain course."
3. **Poetic empty states.** "No classes on the instruments yet. Add the first
   class and the board will come alive — the mission starts there. ✦"
4. **Recovery paths everywhere.** Every error names what happened and what to
   do next. A dead end is a bug.
5. **Plain English first.** Astronaut flavor seasons the copy; it never hides
   meaning. If a user has to guess what a button does, rewrite it.

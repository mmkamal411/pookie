What each check verifies

  • GET / → expect 307Root must redirect unauthenticated visitors to /login. A 500 here means the Pages server function is broken (the 2026-10-12 incident).
  • GET /login → expect 200 + "Pookie" in HTMLLogin shell renders. The content marker catches a 200 that is actually the Next.js error boundary.
  • GET /auth/callback → expect 307Callback with no code must redirect gracefully instead of crashing.
  • GET /api/v1/me → expect 403 + TENANT_SCOPE_VIOLATIONAPI tenant firewall rejects unauthenticated callers with the canonical error envelope.
  • GET /_next/static/… → expect 200One real JS/CSS asset from the login page must serve via Pages. Catches stale bundles and _routes.json regressions.
